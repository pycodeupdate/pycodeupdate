# Code of Conduct

This project has adopted the [PyCodeUpdate Code of Conduct](https://pycodeupdate.github.io/community/code-of-conduct/).

The Code of Conduct defines the standards and expectations for participation across the PyCodeUpdate community. It applies to this repository and to project-related interactions, including issues, pull requests, discussions, code reviews, and other contribution activities.

## Our Commitment

PyCodeUpdate is committed to maintaining an open, welcoming, respectful, and constructive environment for everyone who participates in the project.

Contributors and community members are expected to:

- Treat others with respect and professionalism.
- Communicate constructively and in good faith.
- Welcome different perspectives, technical approaches, and experience levels.
- Keep technical discussions focused on the work rather than individuals.
- Give and receive feedback respectfully.
- Follow the rules and policies of the platforms used to participate in the project.

Unacceptable behavior includes harassment, discrimination, personal attacks, intimidation, deliberate disruption, unwanted sexual attention, publishing private information without consent, and other conduct that is inconsistent with a safe and welcoming open-source community.

## Scope

This Code of Conduct applies to participation in this repository and to project-related activities, including:

- Issues
- Pull requests
- Discussions
- Code reviews
- Documentation contributions
- Commits and other repository contributions
- Project-related communication and community spaces

The canonical [PyCodeUpdate Code of Conduct](https://pycodeupdate.github.io/community/code-of-conduct/) provides the complete standards, scope, reporting process, and enforcement guidance.

## Reporting

If you experience or witness behavior that may violate the Code of Conduct, please report it to the PyCodeUpdate maintainers:

**Email:** [pycodeupdate@outlook.com](mailto:pycodeupdate@outlook.com)

When reporting an incident, include relevant information such as:

- What happened
- When and where it happened
- Links to relevant issues, pull requests, comments, or other material
- The people involved
- Any additional context that may help the maintainers understand the situation

Please avoid publicly sharing sensitive information related to a report.

Reports will be handled as confidentially as reasonably possible and reviewed by the appropriate PyCodeUpdate maintainers.

## No Retaliation

PyCodeUpdate does not tolerate retaliation against anyone who reports a concern in good faith, participates in an investigation, or assists with Code of Conduct enforcement.
